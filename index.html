Simple mobile tool

Register Scanner

Capture a page · Review the text · Export for Google Sheets

1. Capture register page

Page seedha, camera bilkul upar aur roshni achhi rakhein. Agar register mein 2 side/columns hain to pehle Left half ya Right half scan karein.

Photo choose karein. OCR ke liye internet connection zaroori hai.

2. Check and correct text

Save karne se pehle har naam, number aur entry ko original register se compare karein.

OCR ki lines ko naam aur contact mein arrange karne ke liye neeche table banao. Auto-detection sirf andaza hai—har entry register se check karo.

3. Name and Contact table

Har row mein section/heading, naam aur contact alag fields mein hain. Section ka naam paper par likhe heading ke mutabiq edit karo. Auto-detection sirf guess hai.

SECTION / HEADING
NAME
CONTACT NUMBER

CSV Google Sheets mein do columns: Name aur Contact Number ke saath khulegi.

Install on Android

GitHub Pages par app open karne ke baad Chrome menu (⋮) → Install app ya Add to Home screen choose karein. Installation ke liye app HTTPS par host honi chahiye.

Privacy: photo is processed in your browser with the OCR library. Review results before exporting.
